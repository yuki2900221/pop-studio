# POP STUDIO

食料品小売店向けの販促POP作成Webアプリです。WindowsのMicrosoft Edge・Google Chromeでの利用を主に想定しています。

白を基調に、透過・ぼかし・ハイライトを組み合わせたLiquid Glass風UIを採用しています。テンプレートから商品情報を入力し、プレビューを確認して印刷します。

## 公開先

- アプリ: https://pop-studio-yamadaya.mizu-tasks.workers.dev
- GitHub: https://github.com/yuki2900221/pop-studio

## 機能

- 青果・精肉・鮮魚・日配・食品の10テンプレート。
- 商品名、産地・メーカー、内容量・単位、本体価格、見出しラベル、商品画像の編集。
- A4・A5の縦横、棚札148 × 52 mm、文字サイズ、配色の変更。
- 消費税8%・10%、切り捨て・四捨五入・切り上げ、税込価格の表示切り替え。
- 編集プレビューと同じSVGを使用する原寸印刷・ブラウザのPDF保存。1〜20枚を各ページに出力。
- PNG画像と編集用JSONの書き出し、JSONの読み込み。
- ブラウザ内に最大100件を保存、複製・削除、編集の取り消し・やり直し。
- Workers AIによる商品メモからの商品情報抽出。結果を確認してから編集内容へ反映。
- 全画面スケルトン、画面・パネル・ダイアログのアニメーション、モーション軽減設定への対応。

アカウント登録は不要です。下書きとアップロード画像は、そのブラウザのlocalStorageに保存します。端末間同期や店舗間共有はありません。バックアップ・別端末への移動にはJSONを書き出してください。ブラウザのデータ削除で下書きも失われます。

AIボタンを実行した場合に限り、入力した商品メモをCloudflare Workers AIへ送信します。商品画像や保存済みPOPの一覧をAIへ送信する構成ではありません。価格・産地・内容量などが書かれていない場合は推測せず、未入力として扱います。抽出結果は必ず確認してください。

## 開発

Node.js 22.12以上、または対応する新しいLTS版とnpmを使用してください。依存関係は`package-lock.json`で固定します。

```sh
npm install
npm run dev
```

Viteの開発画面が起動します。`/api`は`http://127.0.0.1:8787`のWorkerへ転送されるため、UIのみの起動ではAIは利用できません。APIを含めて開発する場合は、初回にビルドしたうえで別ターミナルからWorkerを起動します。

```sh
npm run build
npx wrangler dev --ip 127.0.0.1 --port 8787
```

`wrangler.jsonc`のAI bindingは`remote: true`です。AI実行にはCloudflareへの認証と利用権限が必要で、ローカル画面からの実行でもCloudflare側の利用枠を消費します。`wrangler dev --remote`もリモート環境・利用枠を使用するため、UIだけを確認する目的では使わないでください。`--local`を指定しても、リモートAI bindingの推論が無料のローカル模擬処理になるわけではありません。

ビルド済み画面とWorkerをまとめて確認する場合は、次を実行します。プレビューは`http://127.0.0.1:4173`です。

```sh
npm run build
npm run preview
```

## 検証

```sh
npm test
npm run build
```

`npm test`は価格計算、保存・読み込み、入力検証、印刷HTML、API・AI応答の異常系を検証します。型検査は`npm run build`にも含まれます。`npm run check`で型検査と自動テストを続けて実行できます。

実施した自動・ブラウザ・公開環境の検証と未実施範囲は[検証記録](docs/testing.md)に記載します。Windows実機と物理プリンターの検証は別途必要です。

`npm run format`でソースを整形し、`npm run format:check`で整形状態を検証できます。GitHub Actionsはpush・PRで型検査、自動テスト、ビルド、依存監査を実行します。公開デプロイは自動化していません。

## Cloudflareへの公開

フロントエンドとAPIをCloudflare Workers + Static Assetsで公開します。Workers AIはサーバー側のAI bindingを使用し、APIキーをブラウザへ配布しません。

```sh
npx wrangler login
npm run deploy
```

デプロイ先とAI・Rate Limiting bindingは`wrangler.jsonc`を確認してください。初回公開時は既存のCloudflare認証を使用し、Wranglerによる直接デプロイを選択しています。Sitesの認証画面や別のAIサービスはアプリへ追加していません。

このコマンドは公開先を更新します。課金プラン変更、独自ドメイン購入、有料サービス追加は含めていません。すでに有料プランのアカウントを使用する場合、契約と利用量に応じた課金はあり得ます。

## 印刷

1. 編集画面の「印刷・PDF保存」で用紙と枚数を確認します。
2. ブラウザとプリンタードライバーを同じ用紙サイズに設定します。
3. 倍率100%、ヘッダー・フッターなしで印刷します。

A4は210 × 297 mm、A5は148 × 210 mm、棚札は148 × 52 mmです。棚札は対応するカスタム用紙設定が必要です。プリンターの印刷可能領域によって余白や欠けが生じるため、普通紙で試し刷りして確認してください。複数種類をA4に面付けする機能は現在含まれません。

ショートカットは`Ctrl+S`で保存、`Ctrl+Z`で元に戻す、`Ctrl+Shift+Z`でやり直し、`Ctrl+P`で印刷設定、`Esc`でダイアログを閉じます。
